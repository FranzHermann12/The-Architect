# The Architect

**An intelligent Minecraft companion built with Fabric.**

The Architect is an experimental Minecraft mod that aims to create an intelligent companion capable of understanding its surroundings, making decisions, and assisting players with various in-game tasks.

The long-term goal is to develop a companion that can interact with the Minecraft world, learn about its mechanics, and help players survive, explore, gather resources, and build.

## Current Features

- **Custom Entity:** A custom entity called The Architect.
- **Summoning Command:** Spawn The Architect using `/architect`.
- **Knowledge Base:** A basic database containing Minecraft crafting, mining, survival, redstone, enchanting, and exploration information.
- **Decision System:** Basic decision-making based on situations such as hunger, danger, and resource requirements.
- **World Awareness:** Reads its own health, condition, and coordinates.
- **Player Interaction:** Responds when the player interacts with it.

## Planned Features

- Natural language command understanding.
- Improved environmental awareness.
- Autonomous movement and navigation.
- Resource gathering and crafting.
- Building assistance.
- Survival and threat awareness.
- More advanced decision-making and planning.

## Technology Stack

- **Language:** Java
- **Mod Loader:** Fabric
- **Game:** Minecraft Java Edition
- **Build System:** Gradle
